# 启思学堂 UI/UX 完整审计

## 结论

产品应保持专业桌面学习工作台，不采用 UI UX Pro Max 检索中偏营销、儿童化、高饱和或横向滚动的推荐。课堂主任务优先于装饰和模块数量。

## 本轮高优先级

- 科目身份：所有区域必须使用同一有效名称；异常历史数据提供恢复入口。
- 桌面窗口：自绘标题栏必须具备可靠拖动、双击最大化和完整窗口按钮。
- 窄窗口：默认减少次要检查器占用，保证讲解、作答和练习宽度。
- 表单反馈：AI 命名失败不能静默降级；错误显示在输入附近并提供下一步。

## 已符合

- 工作台区域层级明确，未使用营销式 Hero 和卡片堆叠。
- 图标使用统一 SVG，主题、字号、面板宽度和折叠状态可持久化。
- 教师内容、学生作答、教学目的和下一步任务已有视觉区分。
- 900×600 与 1200×800 有固定最小尺寸和响应式约束。

## 后续观察

- 长对话中的阶段回顾是否足够明显。
- 练习编辑器打开时主课堂与底部面板的空间分配。
- 主动教师模式实施后，暂停、频率和无障碍状态播报是否完整。

# 学生身份体验验收

每次修改教师模块、课堂界面、练习、测验、课程推进或学习状态后，必须先以学生身份完成一段真实学习，再宣称功能完成。自动测试通过不能替代体验验收。

## 固定体验路径

1. 进入已有科目并确认旧聊天、当前课时和未完成任务恢复正确。
2. 从零开始学习一个新知识点，确认老师先讲清目标、心智模型、例子和边界。
3. 分别输入正确答案、错误答案、“不会”、概念追问和“我想进入下一节”。
4. 完成一次编辑器练习或测验，确认提交、判卷、直接纠错和后续动作一致。
5. 切换科目再返回，确认对话和任务不丢失、不串课。
6. 学完当前知识点，确认有明确的下一节入口，而不是只能新开对话或自行猜测。
7. 在 900×600、1200×800 和 1920×1080 下检查主要操作、输入区和教学内容。

## 教师体验硬门槛

- 教师不得连续发送超过两条消息；反馈和总结可以连续，但必须合并呈现为一个教师话轮。
- 六回合以上的课堂中，带任务的教师回合占比不得超过 45%。
- 六回合以上的课堂中，讲解/示范回合与任务回合比例不得低于 25%。
- 第一次错误必须直接指出关键差异、讲清原因并给出正确答案，不要求原题做到正确为止。
- 学生提出概念问题时暂停原任务，本轮不评分、不催答。
- 获得迁移证据后必须停止同能力的即时检查。
- 总结必须提供明确的“进入下一节”操作；延迟复习不能阻塞当天推进。
- 切换科目、刷新或重启后，聊天、当前任务和证据状态必须一致恢复。

## 每次体验记录

体验记录至少包含：测试日期、版本提交、科目与知识点、学生输入路径、教师任务占比、最长教师连发、是否直接纠错、是否停止检查、是否找到下一节、窗口尺寸、截图或真实会话 ID、发现的问题和复测结果。

- 真实路径：从暂停提示点击“继续练习”，在 CodeMirror 编辑器输入完整代码并点击“提交作答”，等待真实模型批改。
- 恢复结果：编辑器正常展开；提交前后恢复动作未新增教师消息，聊天记录保持 34 条；草稿与原任务一致。

- 修复结果：未完成课时统一显示“继续本节”；继续时按当前教案阶段决定讲解、示范或练习，并明确禁止重复刚通过的练习；任务关闭后同步隐藏过期的暂停提示。

- 继续跟学发现：模型在教案尚处于讲解/练习阶段时连续提前宣称“本节完成”，导致正文、顶部 `1/4`/`2/4` 进度和续学入口互相矛盾；历史恢复后多条被校正的总结又显示为重复文本。

## 2026-08-18 新网关实测（byNara Router + deepseek-v4-pro-free）

- 版本状态：提交见 git 历史（网关兼容性加固 + UI 打磨 + KaTeX）。
- 学生路径：新科目“一元一次方程精讲”→ 入学摸底访谈（有基础 → 2 道口头确认）→ 5 题小测（4 对 1 错）→ 摸底结果 80 分（去括号解方程 0/1，与故意答错一致）→ AI 按薄弱点生成短课（定位→讲解→练习→检查）→ 概念追问“去括号什么时候变号”→ 独立作答 2-(x-4) 得到正确批改 → 继续推进。
- 结果：AI 命名、摸底生成、个性化教案、概念追问暂停原任务、独立判卷与教学复核管线全部在新网关跑通；会话在多次重启后完整恢复；900×600 / 1200×800 / 1920×1080 无横向溢出。
- 新网关兼容问题与修复：
  1. 健康检查聊天探测 10 秒超时对慢速思维链模型太短 → 放宽到 45 秒并增大 max_tokens。
  2. 流式聊天 60 秒总超时会掐断长回答 → 改为 600 秒 + 逐块 120 秒停滞超时；对 402/429/5xx/空回复自动重试两次并退避。
  3. 切换网关后 fast 模型仍指向旧网关（mimo-v2.5）导致科目命名 402 → 保存配置时 fast 跟随 chat。
  4. 思维链模型偶发 content 为 null、内容全在 reasoning_content → 后端回退到推理尾部，避免空回复。
  5. 模型偶发泄漏 `<ds_safety>…</ds_safety>` 与 `.vrtx` 等内部包装 → 解析前统一剥离并加单元测试。
  6. AI 命名失败时不再阻塞建课 → 回退使用学生自己输入的有效名称。
  7. 教师消息中的 LaTeX（\(…\)、\[…\]）原先原样显示 → 引入 KaTeX 渲染。
- 未验证：练习步骤与“进入下一节”入口。测试后期免费网关负载升高，出现中英混杂的无意义输出与内部残留文本，课堂推进无法继续；应用未崩溃，错误与重试入口可用。需在网关恢复后补测，或换用更稳定的网关复测。
- 界面：新增完整深色主题（原深色仅覆盖少数组件）、主题化滚动条、焦点环、消息气泡渐变、节奏步骤勾选态、欢迎页品牌图标与 KaTeX 公式样式；截图 `qisi-student-test/01-06` 供人工复核。

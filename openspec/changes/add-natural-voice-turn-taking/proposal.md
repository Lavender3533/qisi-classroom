# Change: 增加自然教师语音话轮

## Why
现有教师语音虽然支持手动与自动朗读，但新用户默认仍是点击朗读，而且学生开始回答时不会统一打断语音，实际体验仍像带朗读按钮的聊天工具，而不是真正会开口、也会让学生说话的一对一老师。

## What Changes
- 首次使用教师语音时默认采用自动朗读；已经明确选择关闭或点击朗读的用户继续保留原偏好。
- 只自动朗读当前可见课堂中新生成、完成复核并最终渲染的教师消息，历史消息、内部指令、加载状态和候选流内容保持静音。
- 学生聚焦或操作回答区时立即停止教师语音并取得话轮；提交回答后把话轮交还教师。
- 新教师消息开始朗读时取消上一条语音；切换标签、隐藏窗口或离开页面时继续立即停止。
- 浏览器拒绝首次自动朗读时，本次运行降级为消息级点击朗读，并向学生说明降级原因，不反复自动尝试。
- 保留关闭、点击朗读、自动朗读和语速设置，所有用户选择继续持久化。

## Impact
- Affected specs: `natural-voice-turn-taking`（补充并取代 `add-teacher-voice` 中“首次默认点击朗读”的旧默认）
- Affected code: `frontend/teacher-voice.js`、`frontend/app.js`、语音与桌面契约测试
- External services: 无；继续使用 Windows WebView2 本地 Web Speech API

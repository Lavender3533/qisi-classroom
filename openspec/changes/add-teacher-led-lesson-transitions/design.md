## Context
练习提交会形成学生聊天证据，但停靠式小测不会写入聊天历史。课时推进发生在模型回合或小测回调之后，当前没有统一机制在状态变化后安排下一次教师动作。

## Goals / Non-Goals
- Goals: 关键节点由教师主动说话；小测证据进入教师上下文；总结自动且有证据；续讲不重复、不伪造学生发言。
- Non-Goals: 在学生每次点击后都调用模型；第一遍答错时取消本地快速提示；自动开始下一整节新课。

## Decisions
- Decision: 纯函数根据前后课时状态、证据来源和干预状态生成一个续讲计划。
- Decision: 页面内使用单槽队列串行执行续讲；若当前模型回合未结束，则在 `finally` 后立即执行。
- Decision: 续讲命令继续作为临时 system context，复用现有 `internalCommand` 安全边界。
- Decision: 会话保存 `lastTeacherContinuationKey`，同一证据节点最多自动触发一次。

## Risks / Trade-offs
- 连续两次模型请求可能增加等待 -> 只在小测完成、二次错误或进入 summary 时触发，不在首次错误时调用。
- 小测证据不在历史中 -> 续讲命令携带题目、学生答案、支持级别和标准答案；标准答案只在已完成测验后使用。
- 自动总结请求失败 -> 现有失败卡片保留重试按钮，且课时不会被标记完成。

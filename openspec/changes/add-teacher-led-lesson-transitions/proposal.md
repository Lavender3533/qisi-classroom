# Change: 新增教师主动续讲与课堂收尾

## Why
当前随堂测验完成后只更新本地状态，界面虽然写着“老师会继续”，却没有触发教师回复；课时从迁移检查进入总结阶段后，也必须由学生手动点击小结。关键教学节点出现沉默，使课堂仍像带聊天框的练习工具，而不是会掌握节奏的老师。

## What Changes
- 在小测第二次答错后由老师自动接管，依据当前干预主动补讲并给一个更小检查。
- 小测正确后由老师先引用本次证据，再主动开始新的教案步骤；提示后修正时改为无提示再检查。
- 任何学生证据使课时进入 summary 步骤时，老师自动生成有证据的课堂小结，不等待学生点击按钮。
- 主动续讲使用临时系统上下文，不显示、保存或计为学生消息，并通过持久化键避免同一节点重复触发。
- 小测最新证据显式传给续讲回合，防止模型在看不到小测答案时编造总结。

## Impact
- Affected specs: continuous-teaching、formative-assessment
- Affected code: frontend/teacher-engine.js、frontend/app.js、tests、OpenSpec

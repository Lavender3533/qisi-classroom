## ADDED Requirements

### Requirement: 教师动作协议
系统 MUST 为每个教师回合选择一个明确教学动作，并返回学生可理解的本轮目的和下一步任务。模型 MUST NOT 在没有阶段目标的情况下自由延续对话。

#### Scenario: 学生给出错误答案
- **WHEN** 学生的回答包含可定位的概念错误
- **THEN** 教师先指出做对的部分和具体卡点，再选择一个补讲或提示动作，并要求学生完成一个可验证的下一步

#### Scenario: 学生只说懂了
- **WHEN** 学生没有提供新的作答证据
- **THEN** 教师选择检查理解动作且不提高掌握度

### Requirement: 可见的教学意图
系统 MUST 将教师正文与学生下一步作为课堂内容呈现，并在课堂抬头集中显示教学目标；系统 MUST NOT 在每条消息中显示内部编排意图、内部推理或原始结构化协议。

#### Scenario: 教师给出一轮指导
- **WHEN** 模型返回有效教学回合
- **THEN** 学生可以同时看到教师指导、本轮目的和自己应完成的下一步

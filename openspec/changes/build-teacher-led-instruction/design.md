## Context
大模型具备知识，但默认优化目标是回答用户。真实教师的核心差异是持续维护课程目标、选择教学动作、收集证据并根据证据改变下一步。

## Goals / Non-Goals
- Goals: 让每轮交互属于一个清楚的教学动作；让摸底和课堂能够确定性推进；让学生知道老师为什么这样问以及自己下一步做什么。
- Non-Goals: 模拟真人外貌、使用拟人动画、用情绪化文案制造陪伴感。

## Decisions
- Decision: 客户端编排器决定当前访谈阶段和允许的教学动作，模型负责生成学科内容。
- Decision: 教师回合使用结构化 JSON；UI 只展示正文、教学目的和学生任务，不展示内部推理。
- Decision: 学情只能由明确作答证据更新，“懂了”等自我报告不作为掌握证据。
- Alternatives considered: 只强化系统提示词。该方案无法保证跨模型、跨回合稳定推进，因此不采用。

## Risks / Trade-offs
- 结构化输出偶尔失败 -> 保留普通文本降级，但不更新学情。
- 课堂可能显得机械 -> 动作固定、措辞和例子由模型生成，并允许根据错误降级或补讲。

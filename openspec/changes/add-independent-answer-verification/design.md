## Context
现有课堂已经隔离非知识任务、记录待答任务并建立证据门槛，但自由作答的“正确或错误”仍来自主教师模型自己的结构化输出。随堂测验有客户端确定性答案判定，自由问答和开放练习没有同等可信的判卷来源。

## Goals / Non-Goals
- Goals: 在主教师反馈前获得独立、可校验的作答结论；让掌握度与教案推进只接受该结论；失败时安全降级；不暴露答案键。
- Non-Goals: 不把所有开放题简化为字符串完全匹配；不为普通提问、学习选择或课堂确认增加模型调用；不声称同一模型的第二次调用等同于不同机构的仲裁。

## Decisions
- Decision: 使用配置中的 `fast` 模型执行隔离判卷，缺失时回退 `chat` 模型。当前两条路由可能指向同一模型，但独立系统提示、无主教师判断上下文和客户端强制规则仍能消除单回合自判自证。
- Decision: 待答任务新增隐藏 `assessment`：`referenceAnswer`、`criteria`、`acceptableAlternatives`。这些字段持久化但不进入消息尾部、检查器、学生气泡或学习事件明文。
- Decision: 判卷返回 `correct`、`incorrect`、`insufficient` 或 `invalid_task`，并提供置信度、学生答案逐字片段、可核对理由和学生可读反馈。
- Decision: 正确或错误结论必须置信度至少 0.65，且答案片段逐字来自学生本轮消息；否则归为 `insufficient`。
- Decision: 客户端从判卷结果构造小幅学情更新。正确证据的支持级别仍受当前任务是否经过提示或示范约束；模型自报增量只用于一致性观测，不作为权威来源。
- Decision: 判卷请求先于主教师请求。判卷摘要作为客户端教学决策写入独立系统消息，主教师必须据此反馈。
- Decision: 随堂测验已有确定性 `evaluateQuizAnswer`，不进入模型判卷，避免成本和不一致。

## Risks / Trade-offs
- 每个自由作答回合增加一次模型延迟和调用成本 -> 只对 `knowledge_check`、`practice` 的真实作答执行，并在界面明确显示核对状态。
- 同一模型可能在隔离回合中重复同一知识错误 -> 使用隐藏评分契约、严格 JSON 校验和对抗性真实评测降低风险；未来可以无缝替换为不同判卷模型。
- 教师模型与判卷模型结论冲突 -> 客户端结论优先，清除冲突的学情更新和错因，必要时用本地准确反馈替换矛盾句。
- 旧待答任务没有隐藏评分契约 -> 判卷模型根据题目和学科上下文独立求解；若题目不可判定则失败关闭证据，不伪造答案键。

## Migration Plan
1. 新教师回合开始生成隐藏评分契约；旧会话任务按缺少契约的兼容路径判卷。
2. 新增 Tauri 命令，不改变现有流式聊天命令。
3. 判卷功能异常时返回不可用状态，主课堂仍可回复但不写学情。
4. 回滚时旧代码忽略 `assessment` 字段，既有会话仍能读取。

## Open Questions
- 无。当前优先保证正确性和证据可信度，额外一次快速模型调用的实际延迟将在真实评测中记录。

## ADDED Requirements

### Requirement: 可靠窗口拖动
系统 MUST 允许用户从标题栏所有非交互区域拖动窗口，并支持双击非交互区域切换最大化。

#### Scenario: 从品牌或空白标题栏拖动
- **WHEN** 用户按住标题栏品牌区或空白区移动指针
- **THEN** 桌面窗口跟随移动且菜单、搜索和窗口按钮不误触拖动

### Requirement: 窄窗口课堂空间
系统 MUST 在首次以窄窗口打开时优先保证课堂主区域宽度。

#### Scenario: 900px 宽首次打开
- **WHEN** 没有保存布局偏好且窗口宽度小于 1050px
- **THEN** 学习检查器默认收起并仍可由用户手动展开

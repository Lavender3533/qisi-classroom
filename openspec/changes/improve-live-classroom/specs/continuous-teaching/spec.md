## ADDED Requirements

### Requirement: 可恢复的教师响应
系统 MUST 在等待教师模型时持续说明当前状态，并在模型返回 SSE、普通 OpenAI JSON 或无换行流结尾时正确显示回复；失败时 MUST 提供明确原因和重试动作。

#### Scenario: 模型网关返回普通 JSON
- **WHEN** 学生发送回答且兼容网关没有返回 SSE
- **THEN** 系统显示 assistant message 内容而不是无限加载

#### Scenario: 教师响应失败
- **WHEN** 请求超时、响应无内容或格式无法识别
- **THEN** 系统停止加载并提供重新发送本轮回答的动作

### Requirement: 引导式课堂开场
系统 MUST 在新课堂开场提供与诊断目标一致的快捷回答，并在教师消息中显示当前教师身份和教学阶段。

#### Scenario: 学生不知道如何回答开场问题
- **WHEN** 新课堂展示教师的诊断问题
- **THEN** 学生可以选择从基础开始、先接受提问或让老师帮助定位卡点

#### Scenario: 学生进入入学摸底
- **WHEN** 学生打开尚未完成摸底的科目
- **THEN** 系统显示聊基础、做小测、生成计划三步流程，并为首次问题提供基础程度快捷回答

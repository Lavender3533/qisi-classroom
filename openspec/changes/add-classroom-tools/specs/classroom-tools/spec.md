## ADDED Requirements

### Requirement: 唯一课堂工具抽屉
系统 SHALL 在课堂输入入口上方提供随堂画板与计算器图标，并 MUST 使用同一个可调整高度的工具抽屉承载当前工具。

#### Scenario: 打开随堂工具
- **WHEN** 学生激活画板或计算器图标
- **THEN** 系统打开对应工具、保留当前课堂任务，并确保另一工具和代码任务抽屉不同时占用空间

#### Scenario: 收起工具
- **WHEN** 学生关闭工具抽屉
- **THEN** 系统恢复课堂可用空间并保留该科目的未完成工具草稿

### Requirement: 本地随堂画板
系统 SHALL 提供画笔、橡皮、颜色、粗细、撤销、重做与清空，并 MUST 在画布尺寸变化时按笔画模型重放内容而不是拉伸位图。

#### Scenario: 学生绘制草图
- **WHEN** 学生使用鼠标、触控或触控笔在画板绘制
- **THEN** 系统即时显示笔画、支持撤销和重做，并按当前科目恢复未完成草稿

#### Scenario: 插入画板内容
- **WHEN** 学生激活“插入作答”
- **THEN** 系统把当前画板快照作为作答制品附加到当前任务，但不自动提交或发送聊天消息

### Requirement: 受限随堂计算器
系统 SHALL 使用受限表达式解析器计算基础算术、括号和明确允许的常用函数，并 MUST NOT 使用 `eval`、`Function` 或任意代码执行。

#### Scenario: 计算合法表达式
- **WHEN** 学生输入受支持的表达式并请求计算
- **THEN** 系统显示结果、保存本地历史，并允许复制或插入当前作答

#### Scenario: 输入不受支持的表达式
- **WHEN** 表达式包含未知符号、属性访问或不允许的函数
- **THEN** 系统显示可理解的输入错误且不执行任何代码

### Requirement: 工具产物由学生控制
系统 MUST 默认把画板与计算器操作保留为本地临时过程，并 MUST 只在学生显式插入后将产物加入作答。

#### Scenario: 只使用工具但不插入
- **WHEN** 学生在画板绘制或使用计算器后直接关闭工具
- **THEN** 系统不得产生学生消息、不得提交任务、不得据此更新掌握度

#### Scenario: 插入计算结果
- **WHEN** 学生激活计算器的“插入作答”
- **THEN** 系统把表达式和结果插入当前可见作答编辑器并保持未提交状态

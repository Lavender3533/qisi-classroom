# Change: 增加随堂画板与计算器

## Why
学生在课堂中需要临时画图、列关系和做数值计算，但这些过程目前只能混入聊天或依赖外部软件。课堂应提供随手可用、不会自动发送、且能按需插入当前作答的本地工具。

## What Changes
- 在课堂输入区上方增加紧凑工具栏，以图标按钮打开“随堂画板”和“随堂计算器”。
- 两个工具共用一个可调整高度的底部工具抽屉，同一时刻只显示一个工具，避免挤压对话与作答区。
- 画板提供画笔、橡皮、颜色、粗细、撤销、重做、清空和适配画布，并按课程保存未完成草稿。
- 计算器提供基础算术、括号、常用函数、历史记录与键盘输入，使用受限表达式解析器而不是执行任意 JavaScript。
- 工具内容默认只保留在本地；只有学生激活“插入作答”时，结果或画板快照才进入当前任务答案。

## Impact
- Affected specs: `classroom-tools`
- Affected code: `frontend/app.js`、新增课堂工具模块、`frontend/style.css`、本地会话持久化与相关测试
- Data migration: 无；教学会话增加可选工具草稿字段并保持向后兼容
- Dependencies: 计算器应采用小型、受限且经过维护的表达式解析库，禁止直接使用 `eval` 或 `Function`

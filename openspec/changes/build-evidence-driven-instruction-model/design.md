## Context
当前 `knowledge_points` 以模型生成名称作为身份，`mastery` 浮点值被数据库、调度器、学习档案和练习逻辑广泛使用。课时内部已经有任务绑定的证据账本，但它只服务当前 lesson gate，不能跨课时表达稳定知识成分，也不能区分延迟保持。直接替换旧表或重写全部历史风险过高。

## Goals / Non-Goals
- Goals: 让稳定知识成分而非题目措辞成为教学单位；让学习阶段来自追加式可信证据；让客户端确定性控制推进、停止和降级；安全迁移现有用户数据。
- Non-Goals: 一次性建立覆盖所有学科的中央课程库；用复杂概率模型预测成绩；删除旧知识点或重写全部历史聊天；本变更内完成 Parsons 编辑器或完整 PRIMM 教案 UI。

## Decisions

### 1. 规范知识成分目录

- Decision: 新建 `canonical_knowledge_components`，每条记录包含稳定字符串键、科目、名称、描述、前置键、心智模型、边界、示例子目标、对比、误解和表现目标 JSON。
- Decision: 新建 `knowledge_component_aliases`，把旧名称或教师候选名称映射到规范键；别名在科目内唯一。
- Decision: 教师模型只能提出知识成分候选或别名。客户端先做规范化精确匹配；需要语义归并时必须由隔离复核同意且达到高置信阈值，否则创建待审候选，不自动污染已有证据。
- Alternatives considered: 继续以清洗后的名称为键。否决，因为同义表达仍会碎片化，且名称修改会改变身份。

### 2. 追加式证据账本

- Decision: 新建 `knowledge_evidence_records`，记录规范键、证据阶段、任务键、来源、支持级别、正确性、证据摘录、时间与可选延迟间隔；记录只追加，不就地改写历史结论。
- Decision: `introduced` 只能由通过结构化讲解合同的教师回合产生；`recognized`、`guided`、`independent`、`transferred`、`retained` 必须来自与当前任务键和表现目标绑定的可信学生证据。
- Decision: 当前阶段由纯函数从证据记录派生。高阶段不会因一次失败被删除；失败会形成当前缺口、复习优先级或诊断记录。
- Decision: retained 要求与先前学习证据具有最小时间间隔的无提示成功；它不作为当天进入下一知识成分的前置条件。

### 3. 兼容 mastery 投影

- Decision: 迁移期保留旧 `knowledge_points.mastery` 和命令签名。规范知识成分的百分比由阶段、证据新近度和置信度生成只读投影，供旧 UI 暂时显示。
- Decision: 新教学路径不再通过任意 delta 直接决定规范知识成分阶段。旧写入命令只保留兼容记录并产生 `legacy` 来源证据，不得直接越过 independent 或 transferred。
- Alternatives considered: 立即移除 mastery。否决，因为会同时破坏调度、档案、练习和数据导入导出。

### 4. 确定性教学策略状态机

- Decision: 新增纯函数 `decideInstructionalAction`，输入当前知识成分、证据缺口、当前任务、支持级别、错误连续次数、学生意图和前置状态，输出唯一教学动作与允许的任务证据阶段。
- Decision: transferred 成功立即关闭当前即时检查并允许推进；guided 成功最多安排一次新无提示检查；第一次错误直接纠正；第二次同类错误换表示并缩小；第三次检查最小前置知识。
- Decision: 学生概念追问暂停任务；学生明确要求前进时关闭当前任务、保留未验证状态并安排复习，不能通过追加检查强行阻塞。
- Decision: 模型只能在状态机提供的动作合同内生成内容，不能扩大证据范围、重复已关闭任务或自行改变规范知识成分。

### 5. 讲解合同

- Decision: explain/model 回合输出结构化 `instruction_block`：旧知连接、心智模型、带子目标示例、关键对比或边界、小结。
- Decision: 客户端验证字段完整、与当前知识成分一致且没有评分任务后，才记录 introduced；仅有长段文字或 `teacher_move=explain` 不足以成立。

## Risks / Trade-offs
- 语义归并错误会混合无关证据 -> 自动归并必须双重同意并保留原始别名；歧义项默认分开，可回滚映射。
- 双轨状态增加暂时复杂度 -> 把兼容投影集中在单个适配模块，禁止业务代码各自换算。
- 旧历史没有分级证据 -> 只映射为 legacy/introduced 或未知，不补写 independent、transferred、retained。
- 模型可能不稳定输出 instruction block -> 使用本地讲解合同校验，失败时请求一次结构修复；仍失败则不记录 introduced，但允许展示保守讲解。
- retained 的时间阈值依学科而异 -> 第一版使用教学偏好可配置的最小间隔，默认 12 小时，不宣称单一阈值适用于所有学习目标。

## Migration Plan
1. 在数据库迁移事务中创建三张新表和索引，不修改或删除旧表。
2. 为每个已有科目生成规范目录候选；精确/高置信别名建立映射，歧义项保持独立候选。
3. 将旧 mastery、practice_count、correct_count 标记为 legacy provenance，不推断高级证据阶段。
4. 读取路径优先使用规范组件；没有规范记录的科目继续走旧路径并可延迟初始化。
5. UI 先同时展示阶段与兼容百分比，验证稳定后再降低百分比视觉权重。
6. 回滚时停止读取新表即可；旧表和原始数据始终保留。

## Open Questions
- 不同学科 retained 的默认最小间隔是否需要科目模板；第一版采用 12 小时并允许配置。
- 规范知识成分目录是否在未来支持可导入的人工课程包；本变更只保留版本字段，不实现市场或共享。

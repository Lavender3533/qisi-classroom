## ADDED Requirements

### Requirement: 课堂可运行编程实验
系统 SHALL 在编程课堂中提供与当前讲解并行的可运行实验区，使学生能够编辑教师准备的最小工程并查看真实编译和运行结果。

#### Scenario: Java 概念进入动手验证
- **WHEN** 教师完成适合通过运行观察的 Java 概念讲解
- **THEN** 系统 SHALL 在实验区创建与当前知识点绑定的最小 Java 文件
- **AND** 学生 SHALL 能亲手编辑、编译和运行该文件而不离开当前课堂

#### Scenario: 自增表达式真实运行
- **WHEN** 学生运行包含前置与后置自增表达式的 Java 程序
- **THEN** 系统 SHALL 显示 JVM 的真实标准输出或编译错误
- **AND** 教师 SHALL 基于该运行记录解释表达式取值与变量更新的区别

### Requirement: 桌面实验工作区
系统 SHALL 将实验区作为课堂编辑器组内可调整的工作面板，而不是聊天消息或覆盖学习档案的弹窗。

#### Scenario: 宽屏课堂
- **WHEN** 教学工作区具有足够横向空间
- **THEN** 实验区 SHALL 停靠在教学内容右侧并允许调整宽度、收起和最大化
- **AND** 右侧学习档案检查器 SHALL 保持可用

#### Scenario: 窄屏课堂
- **WHEN** 可用宽度不足以并排显示教学内容和实验区
- **THEN** 实验区 SHALL 自动转为可调整高度的底部面板
- **AND** 教学内容、运行按钮和控制台 SHALL 不得重叠或产生横向溢出

### Requirement: 受控本地 Java 执行
系统 MUST 仅在学生显式操作后，以受限本地进程编译和运行课堂 Java 源码，并 MUST 返回结构化结果。

#### Scenario: 程序正常运行
- **WHEN** 学生显式点击运行合法的 Java 实验
- **THEN** 系统 SHALL 在临时目录调用本机 JDK，并返回退出状态、标准输出、标准错误和耗时
- **AND** 运行结束后 SHALL 清理该次编译产物

#### Scenario: 程序包含危险能力
- **WHEN** 源码请求网络、文件、子进程、反射、原生库或系统退出能力
- **THEN** 系统 MUST 在启动编译或运行前拒绝该程序
- **AND** SHALL 显示可理解的拒绝原因

#### Scenario: 程序失控或输出过大
- **WHEN** 程序超过时间或输出限制
- **THEN** 系统 MUST 终止子进程并返回超时或输出受限状态
- **AND** 应用主进程与课堂状态 SHALL 保持可用

### Requirement: 实验结果与学习证据分离
系统 MUST 区分探索性运行记录与经过任务判定的掌握证据。

#### Scenario: 学生只运行程序
- **WHEN** 学生运行或修改实验但未提交当前任务
- **THEN** 系统 SHALL 保存可恢复的实验草稿和观察记录
- **AND** MUST NOT 仅因运行成功而提高知识点掌握度或推进教案

#### Scenario: 学生提交绑定实验
- **WHEN** 学生提交与当前任务键匹配的代码和真实运行结果
- **THEN** 系统 SHALL 将代码、输出和任务要求交给独立验证
- **AND** 只有可信验证结果 SHALL 能作为教案推进证据
